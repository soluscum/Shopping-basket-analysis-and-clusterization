# Анализ покупательских корзин и кластеризация категорий товаров
Проект предназначен для анализа транзакционных данных (чеков) розничной сети. Основная цель — выявить скрытые связи между товарами (подкатегориями) и сгруппировать их в кластеры на основе совместных покупок с помощью алгоритма Leiden.
## Описание
Проект обрабатывает историю покупок за период (октябрь–декабрь) и выполняет:
- расчёт базовой описательной статистики (размер чека, частота категорий, объёмы продаж);
- построение неориентированного взвешенного графа, где вершины — товарные подкатегории, а рёбра — их совместное появление в чеках (вес — частота пары);
- фильтрацию рёбер по минимальной поддержке;
- кластеризацию графа с помощью алгоритма Leiden;
- визуализацию полученных кластеров.
## Используемые данные
Исходные данные представляют собой четыре CSV-файла с разделителем `;`, содержащие следующие столбцы:
- `ChequeId` — идентификатор чека;
- `sub_cat_name` — название товарной подкатегории;
- `cat_name` — название категории (опционально);
- `Штуки товаров в категории` — количество единиц товара.
Файлы объединяются в один DataFrame. Если структура ваших данных отличается, необходимо изменить код чтения и названия колонок.
